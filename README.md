# Grocery Store Billing System

## Overview
The Grocery Store Billing System is a simple Python-based program designed to calculate the total cost of items purchased by a customer. It accepts the price and quantity of five different items, applies a discount if applicable, and displays the final payable amount.

## Summary
This project simulates a basic billing system used in grocery stores.  
The program:
- Accepts price input for 5 items.
- Accepts quantity for each item.
- Calculates the total cost.
- Applies a 10% discount if the total exceeds Rs. 100.
- Displays the original total, discount amount, and final payable amount.

## Technology Used
- Python 3
- Basic Python concepts (loops, conditional statements, user input, arithmetic operations)

## Features
- User-friendly input system
- Automatic total calculation
- Conditional discount application
- Clear bill summary output

## How It Works
1. User enters the price and quantity for 5 items.
2. The system calculates the total cost.
3. If the total exceeds Rs. 100, a 10% discount is applied.
4. The final payable amount is displayed.
